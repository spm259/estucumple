# Es tu Cumple: company context

## Company summary
Es tu Cumple is a birthday reminder product for individuals.
The founder wants to help people wish others happy birthday on WhatsApp.
V1 is a command-based WhatsApp bot that saves birthdays and sends reminders.
The founder is building it as a personal technical challenge, using Codex.
The project is not deployed or in use; the Q4 2026 goal is to launch it.
One founder builds it with limited time and a low budget; customer copy starts in Mexican Spanish.

## How to work
These instructions apply to Codex and Claude Code.
Read this index first. Open only relevant context files, then inspect the code needed for the task.
Follow `constitution.md`. Use the README for setup and engineering commands.
Keep changes small and practical for a solo founder with little time and budget.
Distinguish implemented code, verified behavior, and founder-approved plans.
Use current code to establish implementation facts. Founder answers establish intent.
If sources conflict, state the conflict and ask the founder; do not silently choose a new direction.
Update the relevant context file when the founder confirms a decision. Keep status current and short.

## What not to do
Never invent metrics, customers, quotes, pricing, or roadmap items.
For missing facts, write `UNKNOWN — ask founder`.
Do not promise automatic birthday greetings: current V1 sends reminders to the user.
Do not treat the README's web app or OTP ideas as approved commitments.
Do not add folders, agents, skills, or queue systems unless the founder asks.
Do not replace working engineering instructions with this pack.
